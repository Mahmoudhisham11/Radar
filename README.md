# رادار (RADAR) — نظام ذكاء التسويق وإدارة النمو

> **فلسفة النظام: البيانات الحقيقية المباشرة (Real Data) ← استخراج الذكاء (Intelligence) ← اتخاذ القرار (Decision) ← تنفيذ الإجراءات (Action)**

**رادار (RADAR)** هو منصة ذكاء تسويقي وإدارة نمو متقدمة، مصممة لمراقبة وتحليل قنوات التسويق (مثل تيك توك) وتفاعلات العملاء في الوقت الفعلي، وتوفير تنبيهات فورية، ورؤى ذكية مبنية على بيانات حقيقية 100% بدون أي بيانات وهمية (Zero Mock Data).

---

## 🛠 المعايير التقنية الصارمة للمشروع (Technology Stack)

| الطبقة / التقنية | المعيار المعتمد | القيود الصارمة |
| :--- | :--- | :--- |
| **لغة البرمجة** | **JavaScript & JSX** (`.js`, `.jsx`) | **ممنوع استخدام TypeScript نهائياً** |
| **تنسيق الواجهات** | **CSS Modules** (`*.module.css`) | **ممنوع استخدام Tailwind CSS أو أي أطر Utility** |
| **نظام التصميم** | متغيرات CSS مخصصة (`--radar-*`) في `globals.css` | ثيم داكن فاخر (Obsidian Command Center) ودعم كامل للـ RTL |
| **الواجهة الأمامية** | **Next.js 16** (App Router) + **React 19** | معمارية مكونات معيارية عالية التجاوب |
| **قاعدة البيانات** | **Firebase Firestore** | تخزين التوكنات، الفيديوهات، والتعليقات بأمان وسرية |
| **التكامل الخارجي** | **TikTok Developer Sandbox APIs v2** | ربط رسمي عبر OAuth 2.0 مع إدارة التوكنات على الخادم |
| **محرك التحليلات** | **Deterministic Marketing Analytics Engine** | حساب رياضي قطعي دقيق بدون تخمين الذكاء الاصطناعي |
| **مزود الذكاء** | **OpenRouter API** (Claude / GPT) | استخراج الرؤى والإجابة على الاستفسارات التسويقية |

## 🚀 ما تم إنجازه وبناؤه في التطبيق حتى الآن

### 1. تكامل تيك توك الحقيقي الرسمي (TikTok Developer Sandbox Integration)
- **بروتوكول OAuth 2.0 كامل وآمن:**
  - بدء عملية التفويض عبر المسار `/api/integrations/tiktok/authorize`.
  - معالجة الرد (Callback) والتحقق من CSRF عبر `/api/integrations/tiktok/callback`.
  - تبادل كود التفويض والحصول على `access_token` و `refresh_token` وتخزينها في الخادم وقاعدة البيانات (`connections/tiktok`).
- **نظام التجديد التلقائي للتوكن (Auto Token Refresh):**
  - فحص صلاحية التوكن قبل كل طلب وتجديده تلقائياً عند اقتراب انتهائه.
  - إمكانية طلب التجديد يدوياً عبر `/api/integrations/tiktok/refresh`.
- **محرك المزامنة وإدارة الحساب (Sync & Connection Engine):**
  - جلب بيانات البروفايل الحقيقي (اسم المستخدم، الصورة، المعرف).
  - مزامنة كتالوج الفيديوهات الحقيقية مع كافة إحصائياتها (المشاهدات، الإعجابات، التعليقات، المشاركات، وتاريخ النشر).
  - إمكانية قطع الاتصال الآمن (Disconnect) وإعادة الربط (Reconnect).

### 2. محرك التنبيهات والتعليقات الفورية (Realtime Comment & Notification Engine)
- مسار API مخصص لإدارة التعليقات `/api/integrations/tiktok/comments`.
- نظام تتبع التعليقات التي تحتاج للرد والتعليقات المعالجة.
- **جرس الإشعارات في الهيدر (Notification Bell Dropdown):**
  - شارة تفاعلية بعدد التعليقات غير المعالجة.
  - قائمة منسدلة أنيقة تحتوي على تبويبات ("في انتظار الرد" و "كل التعليقات").
  - زر تفاعلي فوري: `✓ تم الرد على العميل`.
  - حل مشكلات التموضع (Dropdown Positioning) بالكامل وتجاوبها مع اللغة العربية (RTL) والشاشات الكبيرة والموبايل.

### 3. سياسة خلو التطبيق التام من أي بيانات وهمية (Zero Mock Data)
- **حذف وتطهير شامل لكافة البيانات الوهمية والمفبركة** من جميع صفحات التطبيق:
  - إزالة الإيرادات والعملاء والنسب الافتراضية.
  - إزالة المشكلات والفرص الوهمية المكتوبة مسبقاً.
  - إزالة المحادثات والجداول والخطافات الافتراضية.
- اعتماد التطبيق كلياً إما على **البيانات الحقيقية المتدفقة من القنوات المتصلة** أو **شاشات الحالة الصفرية النظيفة (Zero / Empty States)**.

### 4. نظام سياق النشاط التجاري (Business Context System — Phase 3A)
- **هيكل بيانات متكامل في Firestore (`settings/business_context`):**
  - **هوية النشاط (Business):** اسم النشاط، القطاع، المنتج/الخدمة، ووصف العمل.
  - **الجمهور المستهدف (Audience):** شريحة العملاء، ومشكلاتهم ونقاط الألم (Pain Points).
  - **العرض والقيمة (Offer):** العرض الرئيسي، الأسعار، المزايا التنافسية، والدعوة لاتخاذ إجراء (CTA).
  - **الاستراتيجية والتسويق (Marketing):** الهدف التسويقي الرئيسي، الأهداف الفرعية، نبرة البراند، ركائز المحتوى (Content Pillars)، والعروض الحالية.
- **واجهة مستخدم تفاعلية في صفحة الإعدادات (`/settings`):** تتيح التعديل والحفظ التدريجي مع التحقق من صحة المدخلات.

### 5. محرك التحليلات التسويقية الحسابي الدقيق (Deterministic Marketing Analytics Engine — Phase 3A)
- **طبقة حسابية رياضية موحدة ومستقلة:**
  - يستهلك البيانات الموحدة من Firestore دون الاتصال المباشر بتيك توك ودون الاعتماد على الذكاء الاصطناعي في إجراء العمليات الحسابية.
  - **معادلة معدل التفاعل الرسمية:** `((Likes + Comments + Shares) / Views) * 100` مع حماية تامة ضد القسمة على صفر أو إنتاج `NaN / Infinity`.
  - **المتوسطات والإحصاءات:** متوسط المشاهدات، الإعجابات، التعليقات، والمشاركات لكل مقطع، والمقاطع الأعلى والأدنى مشاهدة.
  - **التصنيف والترتيب الرياضي:** تصنيف المحتوى بحسب (المشاهدات، التفاعل %، الإعجابات، التعليقات، المشاركات).
  - **وتيرة النشر (Posting Frequency):** حساب معدل النشر الأسبوعي ومتوسط الأيام بين المقاطع مع حالة `insufficient_data` للبيانات غير الكافية.
  - **فلاتر الفترات الزمنية:** دعم كامل لـ `7d` و `30d` و `90d` و `all`.
  - **تقييم جودة البيانات (Data Quality):** تقارير `complete` و `partial` و `insufficient_data`.
  - **تأسيس واجهة سياق الذكاء المستقبلي:** توفير خدمة `aiContextService.getMarketingContext()` لدمج سياق النشاط والتحليلات الحسابية تمهيداً لمرحلة الاستدلال الذكي القادمة.

### 6. تحسينات الهيدر وتجربة المستخدم (Header & UI Overhaul)
- ضبط التباعد الأفقي والرأسي وارتفاع الأسطر (`line-height`) لمنع تلاصق النصوص في الهيدر.
- معالجة انكسار العناوين الطويلة واقتطاعها بنعومة (`ellipsis`) على شاشات الموبايل لمنع تشويه الواجهة أو تداخل الأزرار.

## 📱 صفحات ووظائف التطبيق الحالية بالتفصيل

### 1. مركز القيادة الرئيسي (`/` — Command Center)
- **شريط التنبيهات الحرجة:** يعرض تنبيهات فورية في حال وجود استفسارات عملاء غير معالجة، أو رسالة نجاح واكتمال عند الرد على الكل.
- **بطاقات الإحصائيات المباشرة:**
  - عدد فيديوهات تيك توك المتزامنة.
  - إجمالي مشاهدات القناة الفعلية.
  - معدل التفاعل الإجمالي المحسوب بدقة رياضية.
  - عدد التعليقات في انتظار الرد.
- **ذكاء رادار التسويقي:** يستخرج تلقائياً الفيديو الأكثر أداءً وتفاعلاً بالقناة ويحلل أرقامه ويوصي بتكرار الزاوية الناجحة.
- **محرك الأهداف النشطة:** متابعة وتيرة نشر الفيديوهات ومطابقتها مع الهدف.
- **حالة وتكامل الأنظمة:** فحص فوري ومباشر لسلامة اتصال Firestore و TikTok Sandbox و AI Provider.

### 2. تكامل تيك توك (`/tiktok` — TikTok Integration)
- بطاقة إدارة الاتصال وعرض حالة الربط مع بيانات الحساب المتصل.
- زر المزامنة الفورية مع إشعارات نجاح المزامنة وعدد الفيديوهات المعالجة.
- ملخص أداء القناة الشامل (المشاهدات، الإعجابات، التعليقات، المشاركات، ومتوسط معدل التفاعل Engagement Rate).
- تبديل طريقة العرض بين **بطاقات الفيديوهات (Cards Grid)** أو **جدول تحليلي منظم (Table View)**.
- قسم إدارة ومتابعة التعليقات مع إمكانية تعليم التعليقات كـ "تم الرد".

### 3. مركز التنبيهات والمتابعة (`/attention` — Attention Center)
- مصفوفة مخصصة لحصر ومتابعة كافة تعليقات واستفسارات العملاء العاجلة عبر فيديوهات تيك توك.
- إمكانية الرد ومعالجة كل تعليق بضغطة زر وتحديث الإشعارات فورياً في كامل التطبيق.

### 4. ذكاء وتحليلات المحتوى (`/content` — Content Intelligence)
- فلاتر الفترات الزمنية (7d, 30d, 90d, all) لتقييم المحتوى.
- تصنيف وترتيب الفيديوهات حسابياً وفق معايير متعددة (الأعلى مشاهدة، الأعلى تفاعلاً %، الأكثر إعجاباً، الأكثر تعليقاً، الأكثر مشاركة).
- استخراج مؤشرات الأداء للأعلى وصولاً والأعلى تفاعلاً.

### 5. سجل العملاء (`/customers` — Customer Intelligence)
- تتبع إجمالي الحسابات المسجلة، متوسط القيمة الدائمة، ومعدل النشاط.
- جدول حسابات العملاء الفعلي مع شاشة حالة فارغة نظيفة جاهزة للربط.

### 6. محرك الأهداف والوتيرة (`/goals` — Goals & Pacing)
- متابعة الهدف التسويقي الرئيسي المستخرج من سياق النشاط التجاري (Business Context).
- قياس وتيرة النشر الفعلية مقابل المستهدف الدوري.

### 7. مركز الذكاء التسويقي (`/intelligence` — Marketing Intelligence)
- تحويل بيانات القناة المتدفقة إلى فرص نمو واضحة قابلة للتنفيذ المباشر.
- رصد أي مشكلات أو اختناقات مع الالتزام بالبيانات الحقيقية فقط، والتمهيد لمرحلة الاستدلال الذكي القادمة.

### 8. إدارة العملاء المحتملين (`/leads` — Lead Pipeline)
- مسار مبيعات منظم يوضح مراحل العملاء (وارد جديد، تم التواصل، مهتم، حجز عرض، مفاوضات، تم الإغلاق).

### 9. مساعد رادار الذكي (`/ask-radar` — Ask RADAR)
- واجهة دردشة تفاعلية مزودة بشرائح استفسارات سريعة للإجابة على الأسئلة التسويقية وتحليل أداء المحتوى.

### 10. إعدادات سياق النشاط والنظام (`/settings` — Settings & Context)
- واجهة تفاعلية شاملة لتهيئة سياق النشاط التجاري (الهوية، الجمهور، العرض، والأهداف التسويقية).
- تشخيص وفحص صحة خدمات النظام والاتصالات (System Health Monitor).

## ⚙️ متطلبات التشغيل والتهيئة (Setup & Running)

### 1. إعداد المتغيرات البيئية (`.env.local`)
أنشئ ملف `.env.local` في مسار المشروع الرئيسي وأضف المفاتيح التالية:
```bash
# TikTok Developer Sandbox Credentials
TIKTOK_CLIENT_KEY=your_tiktok_client_key
TIKTOK_CLIENT_SECRET=your_tiktok_client_secret
TIKTOK_REDIRECT_URI=http://localhost:3000/api/integrations/tiktok/callback
TIKTOK_SANDBOX_MODE=true

# Firebase Configuration
FIREBASE_PROJECT_ID=your_project_id
FIREBASE_CLIENT_EMAIL=your_client_email
FIREBASE_PRIVATE_KEY="your_private_key"

# OpenRouter AI Key
OPENROUTER_API_KEY=your_openrouter_key
```

### 2. أوامر التشغيل والاختبار
```bash
# تثبيت الحزم
npm install

# تشغيل خادم التطوير
npm run dev

# تشغيل اختبارات المرحلة 3A
npm run test:phase3a

# تشغيل كافة اختبارات النظام
npm run test:tiktok
npm run test:phase2

# فحص البناء والإنتاج
npm run build
```
